# ⏳ Alive Since — Modern Life & Temporal Calculator

**Alive Since** is a state-of-the-art, high-aesthetic web application that measures your life through time, space, biology, celestial mechanics, and historical epochs. Built with React, Vite, and TailwindCSS, every calculation runs 100% locally in your browser with zero data stored or transmitted.

---

## ✨ Features Overview

### 1. ⏱️ Live Age & Temporal Units Calculator
- **Real-Time Live Counter**: Ticking live counters tracking your exact age down to the second.
- **Multiple Time Units**: View your total lifespan in Years, Months, Weeks, Days, Hours, Minutes, and Seconds.
- **Leap Year Verification**: Handles Gregorian leap years with astronomical precision.

---

### 2. 🔀 Date Comparison Engine
- **Compare Two Timelines**: Enter a second person's date of birth to visually compare life timelines.
- **Detailed Differences**: Shows exact difference in years, months, and days (using full words, e.g., *4 months 29 days*).
- **Next Birthday Countdown Comparison**: Identifies who is older, next birthday countdowns, and the gap between upcoming birthdays.
- **Milestone Race**: Highlights which person reaches specific lifespan milestones first.

---

### 3. 🎯 Life Milestones & Countdowns
- **Past & Upcoming Milestones**: Tracks 1,000 Days, 5,000 Days, 10,000 Days, 25,000 Days, 100,000 Hours, 500,000 Hours, and 1 Billion Seconds.
- **Live Countdowns**: Real-time countdown timers to your next major temporal milestone.

---

### 4. 📅 Any Date Temporal Calculator
- **Calculate Age on Specific Dates**: Discover how old you were (or will be) on any historic, personal, or future date (e.g., *Graduation Day, Year 2050, Apollo Moon Landing*).

---

## 🛠️ Technology Stack

- **Core**: React 18, Vite 8, JavaScript (ES2022)
- **Styling**: Vanilla CSS3 + TailwindCSS (Dark/Gold Luxury Aesthetics)
- **Icons**: Lucide React
- **Privacy**: 100% Client-side execution in local browser memory (No tracking, no analytics, no remote database)

## 🚀 Local Development Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/YOUR_USERNAME/alivesince.git
   cd alivesince
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
